## How I work

I like product problems where multiple technical actors and asynchronous states have to resolve into one understandable, reliable outcome for the user or integration partner. My approach is usually:

1. Understand partner/user pain and business constraints
2. Map the transaction lifecycle and edge cases
3. Define product states, API behavior, and operational ownership
4. Instrument the flow before launch
5. Ship with monitoring and recovery paths
6. Use data and support signals to prioritize iteration
